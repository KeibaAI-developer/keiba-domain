# race_code.py

16桁レースコードの形式の検証と、各要素への分解を提供する。

レースコードは `年（4桁） + 月日（4桁） + 競馬場コード（2桁） + 回（2桁） + 日目（2桁） + R（2桁）` を連結した文字列である。

## `RACE_CODE_LENGTH`

レースコードの桁数。

| 型 | 値 |
|---|---|
| `int` | `16` |

---

## `validate_race_code()`

### 概要

16桁レースコードの形式を検証する。

### 引数

| 引数 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `race_code` | `str` | - | 16桁レースコード（例: `"2026111508050411"`） |

### 返り値

なし。

### 補足

半角数字16桁だけを正しい形式とする。
全角数字や、前後に空白・改行が付いた文字列は不正とする。
検証したレースコードをパスや SQL に埋め込む利用側が、想定外の文字を受け取らないようにするためである。

### 例外

| 例外 | 条件 |
|---|---|
| `KeibaDomainError` | `race_code` が半角数字16桁でない場合 |

---

## `extract_race_code_parts()`

### 概要

レースコードから各要素を抽出する。

### 引数

| 引数 | 型 | デフォルト値 | 説明 |
|---|---|---|---|
| `race_code` | `str` | - | 16桁レースコード |

### 返り値

| 型 | 説明 |
|---|---|
| `dict[str, str]` | 各要素を含む辞書 |

| キー | 説明 | 例（`"2026111508050411"`） |
|---|---|---|
| `年` | 開催年（4桁） | `"2026"` |
| `月日` | 開催月日（4桁） | `"1115"` |
| `競馬場コード` | 競馬場コード（2桁） | `"08"` |
| `回` | 開催回（2桁） | `"05"` |
| `日目` | 開催日目（2桁） | `"04"` |
| `R` | レース番号（2桁） | `"11"` |

### 例外

| 例外 | 条件 |
|---|---|
| `KeibaDomainError` | レースコードの形式が不正な場合 |
