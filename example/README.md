# example/

このディレクトリにライブラリの使用例スクリプトを配置してください。

## example_keiba_domain.py

`keiba_domain` の主要な公開APIを一通り呼び出すサンプルスクリプトです。競馬場・馬場状態・
距離区分・枠・コースのモジュールごとに判定関数を呼び出し、結果を表示します。中央10場以外の
競馬場コードや範囲外の馬場状態コードなど、例外が送出される入力も併せて表示します。

外部データ（DB・ネットワーク・ファイル）には依存せず、引数なしで実行できます。

```bash
python example/example_keiba_domain.py
```
